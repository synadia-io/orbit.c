NATS_EXTERN natsStatus natsCounter_GetFromStream ( natsCounter ** counter,
jsCtx * js,
const char * stream )

Creates a counter client for the named stream.

The stream must have both allow_msg_counter and allow_direct enabled.

On success, *counter is set to a newly allocated natsCounter; the caller is responsible for destroying it with natsCounter_Destroy().

Parameters
counterreceives the newly allocated counter.
jsJetStream context.
streamname of the stream.
Returns
#NATS_OK on success, #NATS_INVALID_CONFIG if a required stream flag is absent.
