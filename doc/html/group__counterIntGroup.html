Detailed Description

These functions accept and return long long values. Use the *Str variants for counters that may exceed the range of long long.

Adds delta to the counter for subject.

The server atomically increments the stored value and echoes the new total in the PubAck response. delta may be negative (subtraction).

Parameters
counterthe counter.
subjectthe subject to modify.
deltaamount to add (may be negative).
newValuereceives the resulting total.
Returns
#NATS_OK on success, #NATS_ERR if the resulting value exceeds long long.

const char * subject,
long long delta,
char ** newValue )

Adds delta to the counter for subject, returning the result as an arbitrary-precision decimal string.

This is the C equivalent of Go's AddInt(ctx, subject, value) (*big.Int, error). The delta is a convenient long long, but the returned value will never overflow because it is a heap-allocated decimal string.

Parameters
counterthe counter.
subjectthe subject to modify.
deltaamount to add (may be negative).
newValuereceives a newly allocated string; caller must free().
Returns
#NATS_OK on success.
