Fetches the full counter entry for subject.

Includes the current value, the last increment, and source tracking information.

On success, *entry is set to a newly allocated natsCounterEntry; the caller must destroy it with natsCounterEntry_Destroy().

entryreceives the newly allocated entry.

NATS_EXTERN natsStatus natsCounter_GetMultiple ( natsCounterEntryList * outList,
natsCounter * counter,
const char ** subjects,
int numSubjects,
uint64_t timeout )

Fetches counter entries for multiple subjects in a single batch.

Issues one batched DIRECT.GET request (ADR-31 multi-last) for the given subject list and returns a natsCounterEntryList containing one entry per matching subject. Non-existent subjects are silently skipped by the server, so the returned list may be shorter than numSubjects. subjects may contain NATS wildcard tokens.

The call blocks until the server's end-of-batch sentinel arrives or timeout elapses.

On success, *outList owns the returned entries; the caller must release them with natsCounterEntryList_Destroy(). When numSubjects is 0 (or subjects is NULL), *outList is set to an empty list and #NATS_OK is returned without contacting the server. On error, *outList is unchanged.

Parameters
outListreceives the populated entry list.
counterthe counter.
subjectsarray of subject strings.
numSubjectsnumber of elements in subjects. Must not exceed the server's multi-last cap (1024).
timeoutmaximum time to wait, in milliseconds. Must be > 0 unless numSubjects is 0.
Returns
#NATS_OK on success, #NATS_NOT_FOUND if no subject matched, #NATS_TIMEOUT if timeout elapsed before the batch completed.
