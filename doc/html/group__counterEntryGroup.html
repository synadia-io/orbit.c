natsStatus natsCounter_Get ( natsCounter * counter,
const char * subject,
natsCounterEntry ** entry )

Fetches the full counter entry for subject.

Includes the current value, the last increment, and source tracking information.

On success, *entry is set to a newly allocated natsCounterEntry; the caller must destroy it with natsCounterEntry_Destroy().

Parameters
counterthe counter.
subjectthe subject to fetch.
entryreceives the newly allocated entry.
Returns
#NATS_OK on success, #NATS_NOT_FOUND if the subject has never been written.

natsStatus natsCounter_GetMultiple ( natsCounter * counter,
const char ** subjects,
int numSubjects,
natsCounterIterFn handler,
void * closure )

Fetches counter entries for multiple subjects in a single batch.

The handler callback is invoked once per result, in an unspecified order. Non-existent subjects are silently skipped. When all results have been delivered, the callback is invoked one final time with status=#NATS_OK and entry=NULL to signal completion.

subjects may contain NATS wildcard tokens; see ADR-49 for details.

Parameters
counterthe counter.
subjectsarray of subject strings.
numSubjectsnumber of elements in subjects.
handlercallback invoked once per result.
closureuser-supplied pointer forwarded to handler.
Returns
#NATS_OK on success.
